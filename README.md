# Conectaí

> Social IRL — technology designed to turn online connections into real-life friendships.

Conectaí is a cross-platform social application focused on helping people discover compatible friendships, create real-world plans, join small social activities, and build meaningful offline connections.

## Product Vision

Most social platforms optimize for screen time.

Conectaí is designed around a different metric:

**Real-life connections generated.**
